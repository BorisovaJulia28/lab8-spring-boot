# Лабораторная работа №8

Приложение управления студентами с регистрацией и входом.

Стек: Java 17, Spring Boot 2.7.8, Spring Security, Thymeleaf, H2.

## Запуск

1. Открыть Maven-проект в IntelliJ с JDK 17.
2. Создать в корне проекта папку testdb.
3. Через DBeaver создать базу H2 Embedded: testdb/students.
   Драйвер 2.1.214, пользователь sa, пароль пустой.
4. Отключить соединение DBeaver.
5. Запустить Lab8Application из корня проекта.
   Таблицы создаются автоматически, ddl-auto=update сохраняет данные.
6. Открыть http://localhost:8080/ и зарегистрировать пользователя.

После входа доступны список студентов и список пользователей.
Пароли сохраняются в виде хешей BCrypt.
